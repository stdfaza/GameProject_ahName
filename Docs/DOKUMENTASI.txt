2. SISTEM ONLINE SCOREBOARD & USERNAME (INTEGRASI SERVER)
--------------------------------------------------------------------------------
Game terhubung dengan backend server HTTP REST API untuk leaderboard global.

A. Spesifikasi Endpoint Server:
   - URL: http://192.168.1.5:5000/api/scores
   - Method: POST
   - Headers: "Content-Type: application/json"
   - Payload JSON:
     {
       "player": "CODENAME",
       "style": 650.0,
       "wave": 3
     }
   - Response: 201 Created {"status": "ok"}
   - Leaderboard GET: Mengembalikan array top 10 skor tertinggi terurut desc.

B. Alur Username & Menu Awal:
   1. Layar Menu Awal (Start Menu):
      - Game dimulai dalam kondisi paused-input (mouse mode VISIBLE).
      - Menampilkan instruksi kontrol dan form input "ENTER CODENAME".
   2. Penyimpanan Nama Persisten (Persistent Storage):
      - Godot: Tersimpan di file konfigurasi lokal `user://player_data.cfg`.
      - Web: Tersimpan di browser via `localStorage.getItem('scorched_player_name')`.
      - Pemain tidak perlu mengetik ulang namanya setiap kali membuka game.
   3. Trigger Pengiriman Skor:
      - Skor terkirim otomatis saat pemain mati (Game Over) atau menang (Victory).
      - Nilai yang dikirim: Nama pemain, akumulasi Style Points, dan Wave tercapai.
   4. Auto-Cleanup HTTP Node:
      - Pada Godot, node HTTPRequest di-instansiasi saat pengiriman dan otomatis
        dihapus dari memory (`queue_free()`) setelah request selesai, mencegah memory leak.

3. KARAKTER & ABILITY (PLAYER CONTROLLER)
--------------------------------------------------------------------------------
A. Status & Resource:
   - HP (Hit Points): Base 100. Regen utama BUKAN pasif, melainkan menyerap
     darah musuh jarak dekat (Blood Heal Mechanic).
   - Stamina: 3 Bar. Regenerasi otomatis (0.65 detik per bar).
     Dipakai untuk Dash dan Ability Shockwave/Parry.
   - Style Meter:
     * Ranking: DESTRUCTIVE -> ANARCHY -> BRUTAL -> CHAOS -> SSSLAYER -> ULTRAKILL.
     * Mekanik: Bertambah saat ganti senjata, bunuh cepat, parry, dan melee.
     * Decay: Berkurang perlahan setiap detik jika tidak ada aksi kombat.

B. Pergerakan (Movement):
   - WASD / Analog: Gerak horizontal (kecepatan dasar tinggi: 13 unit/detik).
   - Space: Jump (kecepatan lompat vertikal: 11 unit/detik).
   - Shift (Dash): Konsumsi 1 bar stamina. Instan tele-dash ke arah pandangan
     (34 unit speed, durasi 0.14 detik) untuk dodge serangan proyektil musuh.

C. Senjata & Serangan (Arsenal):
   - Slot 1: SHOTGUN (Tombol 1)
     * Karakteristik: Tembakan menyebar (7 pellet per tembakan), damage tinggi
       jarak dekat (24 dmg/pellet). Cooldown 0.45s.
     * Style bonus: +4 STYLE ("SHOTGUN BLAST").
   - Slot 2: REVOLVER (Tombol 2)
     * Karakteristik: Proyektil berkecepatan tinggi presisi tajam, 90 damage. Cooldown 0.4s.
     * Style bonus: +10 STYLE ("REVOLVER SHOT").
   - Slot 3: CRYO-RIFLE (Tombol 3)
     * Karakteristik: Proyektil elemen es penetrasi api, 25 damage. Cooldown 0.18s.
     * Style bonus: +6 STYLE ("CRYO SHOT").
   - Klik Kanan: KNIFE (MELEE / BLOOD ABSORPTION)
     * Karakteristik: Serangan pisau jarak dekat (radius 4.2 unit), 65 damage.
     * Efek Khusus: Menyerap darah musuh -> Pulihkan +20 HP & +1 Stamina per hit.
     * Style bonus: +25 STYLE ("BLOOD ABSORPTION").
   - Tombol E: SHOCKWAVE & PARRY
     * Konsumsi: 1 bar stamina. Cooldown 0.45s.
     * Efek 1 (Shockwave): Mendorong mundur musuh dalam radius 6.5 unit sejauh 24 unit force.
     * Efek 2 (Parry): Jika memukul fireball musuh dalam radius 6.5 unit:
       - Proyektil berubah warna (Cyan Neon).
       - Kecepatan berlipat ganda (90 unit/detik).
       - Memantul balik tepat ke arah crosshair kamera pemain.
       - Damage proyektil naik drastis (100 damage / Instant Kill).
     * Style bonus: +45 STYLE ("PARRY REFLECT").

4. ENEMY BEHAVIOR & ARCHETYPE (10 FIRE MONSTERS)
--------------------------------------------------------------------------------
Sumber Asset: "16 Fire Monsters Animated Pixel Art Creature Pack" by sassion (itch.io)
Tipe Rendering: Animated Billboard Sprite (Menghadap kamera secara otomatis)
Animasi: 4-frame sprite sheet per karakter (@ 64x64 px).

A. Roster Musuh & Stat:
   1. Devil (Fire Devil)
      - Tipe: Ranged Caster / Skirmisher
      - Scale: 2.8 | Speed: 4.0 | Base HP Multiplier: 1.0x
      - Behavior: Jaga jarak menengah (~15-25 unit), menembakkan fireball merah.
   2. Golem (Fire Golem)
      - Tipe: Heavy Tank / Melee Brute
      - Scale: 3.4 | Speed: 2.5 | Base HP Multiplier: 2.2x
      - Behavior: Bergerak lambat maju menuju pemain, serangan kontak fisik (14 damage).
   3. Hound (Fire Hound)
      - Tipe: Fast Rusher / Flanker
      - Scale: 2.4 | Speed: 5.5 | Base HP Multiplier: 0.8x
      - Behavior: Kecepatan lari tinggi, mengejar pemain agresif untuk gigitan melee.
   4. Dragon (Large Dragon)
      - Tipe: Mini-Boss / Heavy Ranged
      - Scale: 3.6 | Speed: 3.2 | Base HP Multiplier: 2.5x
      - Behavior: HP tebal, menembakkan fireball beruntun tiap 2.6 detik.
   5. Elemental (Fire Elemental)
      - Tipe: Agile Ranged
      - Scale: 2.2 | Speed: 5.0 | Base HP Multiplier: 0.6x
      - Behavior: Gerakan lincah, menembakkan proyektil dari sudut tak terduga.
   6. Flower (Fire Flower)
      - Tipe: Turret / Area Denial
      - Scale: 2.5 | Speed: 2.0 | Base HP Multiplier: 1.3x
      - Behavior: Sangat lambat, menembakkan proyektil api berkala ke arah pemain.
   7. Ghost (Fire Ghost)
      - Tipe: Floater / Ambusher
      - Scale: 2.4 | Speed: 4.5 | Base HP Multiplier: 0.8x
      - Behavior: Melayang di atas tanah, mengejar pemain sambil melepaskan bola api.
   8. Lantern
      - Tipe: Swarm / Scout
      - Scale: 2.2 | Speed: 3.5 | Base HP Multiplier: 0.9x
      - Behavior: Meluncur mendekat, menabrakkan diri untuk melee damage.
   9. Magma (Magma Slime)
      - Tipe: Support Ranged
      - Scale: 2.0 | Speed: 2.2 | Base HP Multiplier: 0.9x
      - Behavior: Ukuran kecil, sulit dibidik shotgun dari jauh, menembakkan proyektil.
   10. Crab (Fire Crab)
       - Tipe: Armored Bruiser
       - Scale: 2.4 | Speed: 3.2 | Base HP Multiplier: 1.1x
       - Behavior: Tahan peluru ringan, mengejar lurus untuk serangan capit melee.

B. AI State Machine:
   - State 1: SPAWN -> Muncul di perimeter arena (radius 16 - 34 unit).
   - State 2: CHASE -> Hitung vektor arah menuju pemain (ignoring Y axis).
   - State 3: ATTACK:
     * Ranged (interval 2.6s): Spawn instance fireball dengan arah Player.Position.
     * Melee (interval 1.5s, jarak < 2.8 unit): Panggil take_damage() pada pemain.
   - State 4: HURT -> Flash warna putih/oranye singkat (80ms), menerima knockback impuls.
   - State 5: DIE -> Signal died di-emit, beri style point ke player, queue_free().

5. PROYEKTIK & PARRY MECHANIC (FIREBALL)
--------------------------------------------------------------------------------
- Default Fireball:
  * Speed: 24 unit/detik.
  * Lifetime: 5 detik.
  * Collision Layer: Layer 4 (Fireball), Mask 1 (Player) & 2 (World).
  * Damage ke pemain: 22 HP + Layar Flash Merah.
- Parried Fireball (Dipantulkan tombol E):
  * is_parried flag: True.
  * Warna visual: Berubah dari Merah Api ke Cyan Listrik bercahaya.
  * Speed: Meningkat drastis ke 90 unit/detik.
  * Arah: Ditentukan oleh vektor hadap kamera (-camera.global_transform.basis.z).
  * Damage ke musuh: 100 damage (Instant kill pada monster non-boss).

6. STAGE & LEVEL DESIGN (SCORCHED ARENA)
--------------------------------------------------------------------------------
A. Lingkungan Visual:
   - Background Mode: Solid Color gelap kemerahan pekat (#140602).
   - Fog: Distance/Volumetric fog tebal (#1a0703, densitas 0.02) memberikan atmosfer
     inferno berasap dan membatasi horizon.
   - Lighting: Ambient light oranye kemerahan (#ff5522) + Directional Sun api (#ffaa44).
   - Floor: StaticBody3D lantai batu hangus 160x160 unit (#180904).
   - Obstacles: 25 pilar kerucut batu hangus (burnt spires) dengan variasi tinggi
     (8 - 16 unit) sebagai cover pemain dari tembakan proyektil.

B. Wave Progression:
   - Total Wave: 3 Gelombang survival.
   - Wave 1: 6 musuh simultan. Musuh dasar (Devil, Golem, Hound, dll).
   - Wave 2: 12 musuh simultan. Variasi monster meningkat.
   - Wave 3: 18 musuh simultan. Semua variasi monster muncul bersamaan.
   - Victory Condition: Semua musuh di Wave 3 tereliminasi -> Muncul layar VICTORY.
   - Defeat Condition: HP pemain mencapai 0 -> Muncul layar YOU DIED + tombol restart.

7. USER INTERFACE (HUD ULTRAKILL-STYLE)
--------------------------------------------------------------------------------
A. Kiri Bawah:
   - Angka HP merah tebal (font monospace, ukuran 46px, shadow hitam).
   - 3 bar cyan untuk Stamina (modulate redup saat kosong).
   - Indikator Senjata Aktif: [1] SHOTGUN / [2] REVOLVER / [3] CRYO-RIFLE.
B. Kanan Bawah:
   - Style Rank huruf kapital besar (DESTRUCTIVE, BRUTAL, ULTRAKILL, dll).
   - Meter progress bar oranye pengisi style.
C. Layar Tengah & Atas:
   - Teks WAVE X / 3 di posisi tengah atas (oranye terang ber-shadow hitam).
   - Crosshair bentuk "+" cyan neon tepat di tengah layar.
   - Damage overlay (ColorRect layar penuh flash merah transparan saat terkena hit).
